Troubleshooting

Start with setup checks in Console. Findings use the returned config; they do not inspect your Console drafts or publication status. Suggestions are checks to try, not confirmed causes.

Console setup checklist
  1. Flows → Publishing: confirm the organization, public API key, Flow ID, platform, and staging or production selection match this test. Confirm publication completed successfully.
  2. Flows → Regulations / Regulation Manager: check the attached regulation, country and region coverage, settings, frameworks, vendors, and purposes. Save regulation edits and apply any updates offered in the Flow.
  3. Flows → Privacy Widgets: check each regulation’s assigned widgets, default widget, priority, and display rules. Review location, URL, manual display, and any other conditions. Save widget edits and check language coverage.
  4. Brand Manager / Flows → Privacy Widgets: save the intended brand profile and theme; confirm the Flow uses that brand and apply any offered updates.
  5. Flows → Publishing: save and publish the updated Flow to the environment selected here, then reload. Editing a draft alone does not update a published Flow. Clear unintended sandbox overrides before comparing results.

Waiting for diagnostics. If startup fails, check the messages below and your browser Console.
